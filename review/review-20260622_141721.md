## Overview

`runner.js` is a bundled/compiled CLI runner that orchestrates AI coding operations across multiple providers (Claude, OpenCode, AI SDK). While the GitHub issue #5 is a frontend UI task about displaying categorized questions, this file represents the backend agent runtime that generates the content. The following are **major bugs** found in the code.

## Major Bugs

### BUG 1: Incorrect `totalTokens` Calculation in `modelUsageToTokenUsage` (Line 151-169)

```javascript
const totalTokens = inputTokens !== void 0 || outputTokens !== void 0
  ? (inputTokens ?? 0) + (outputTokens ?? 0)
  : void 0;
```

**Problem:** The condition uses `||` (OR) instead of `&&` (AND). This means `totalTokens` is computed even when only ONE of `inputTokens` or `outputTokens` is defined, leading to potentially misleading totals.

**Impact:** Incorrect token usage reporting in billing/analytics.

**Fix:** Change the condition to:
```javascript
const totalTokens = inputTokens !== void 0 && outputTokens !== void 0
  ? (inputTokens ?? 0) + (outputTokens ?? 0)
  : void 0;
```

### BUG 2: `resolveSession` Ignores Input for `queryOption.sessionId` (Line 202-208)

```javascript
function resolveSession(input) {
  const correlationId = input && input.length > 0 ? input : randomUUID();
  return {
    sessionId: correlationId,
    queryOption: { sessionId: randomUUID() }  // <-- BUG: always generates new UUID
  };
}
```

**Problem:** The `queryOption.sessionId` always gets a freshly generated UUID, completely ignoring the `correlationId` that was intentionally computed from the input. This breaks session continuity when the caller explicitly provides a session ID.

**Impact:** Cannot correlate SDK messages across multiple calls; session tracking is broken.

**Fix:**
```javascript
queryOption: { sessionId: correlationId }
```

### BUG 3: Greedy Regex in `salvageStructured` (Line 1339-1344)

```javascript
const match = text.match(/\{[\s\S]*\}/);
```

**Problem:** The `[\s\S]*` is greedy and will match from the first `{` to the **last** `}` in the entire text. If the model output contains multiple JSON-like objects or nested braces, this regex captures far too much content, causing `JSON.parse` to always fail.

**Impact:** Structured output recovery from text fallback never works when there's any surrounding text, defeating the salvage mechanism entirely.

**Fix:** Use a non-greedy match or balanced brace matching:
```javascript
const match = text.match(/\{[\s\S]*?\}(?=\s*$)/);
// Or better: find the last } by scanning from the end
```

### BUG 4: Overly Aggressive `..` Rejection in `isWindowsPathOutside` (Line 272-278)

```javascript
function isWindowsPathOutside(root2, tok) {
  const norm = (p) => p.replace(/\//g, "\\").toLowerCase().replace(/\\+$/, "");
  const t = norm(tok);
  if (t.includes("..")) return true;  // <-- BUG: always denies paths with ".."
  // ...
}
```

**Problem:** Any path containing `..` is immediately rejected as "outside workspace" without checking whether the `..` actually escapes the root. A legitimate path like `./src/../index.js` (which resolves to `./src/index.js` inside the workspace) would be blocked.

**Impact:** Legitimate relative paths using `..` are denied, breaking normal file operations.

**Fix:** Resolve the full path first, then check if it's within the workspace:
```javascript
function isWindowsPathOutside(root2, tok) {
  const norm = (p) => p.replace(/\//g, "\\").toLowerCase().replace(/\\+$/, "");
  const t = norm(tok);
  const r = norm(root2);
  // Resolve the path (accounting for ..) before checking
  const resolved = resolvePath(r, t);  // would need node:path resolve
  const normResolved = norm(resolved);
  return !(normResolved === r || normResolved.startsWith(r + "\\"));
}
```

### BUG 5: `findBashEscape` Regex Excludes `)` from Path Tokens (Line 262)

```javascript
const absTokens = command.match(/(?<![\w/=])\/[^\s'";|&)<>]+/g) ?? [];
```

**Problem:** The negative character class `[^\s'";|&)<>]` excludes `)` from path matching. This means paths containing `)` (e.g., `/path/to/file (copy)/subdir`) would be partially matched or missed entirely, allowing potential path escape through such paths.

**Impact:** Security bypass — paths with `)` characters can escape workspace confinement.

**Fix:** Remove `)` from the exclusion list:
```javascript
const absTokens = command.match(/(?<![\w/=])\/[^\s'";|&<>]+/g) ?? [];
```
