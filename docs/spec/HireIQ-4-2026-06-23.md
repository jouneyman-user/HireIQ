## Issue Summary

Implement a `POST /generate` endpoint on the FastAPI backend that accepts a candidate's resume text and role details, calls the Anthropic Claude API, and returns at least 3 tailored interview questions in each of three categories (Technical, Behavioural, Culture Fit). Each question includes a suggested follow-up and a "what to listen for" coaching note. Claude API errors are caught and surfaced as `502` responses with a user-friendly message.

---

## Problem Statement

HireIQ's core value proposition is AI-generated, tailored interview questions. Milestone 1 established the foundation scaffold (FastAPI backend, SQLite, React frontend) and Issue #2 added resume upload and storage. This issue delivers the intelligence layer:

- There is no endpoint that invokes the Claude AI model.
- Recruiters cannot generate interview questions from stored resume data.
- The output must be structured and categorised so downstream UI components (M3) can render it meaningfully.

## Implementation Details

### Architecture

```
Client (React / curl / test)
  │  POST /api/generate
  │  { resume_text, job_title, seniority_level, key_skills }
  ▼
FastAPI  →  POST /generate  (backend/app/routers/generate.py)
  │
  ├── Validate request body (Pydantic + manual checks)
  ├── Call generate_interview_questions() from claude_service.py
  │     ├── Build structured prompt with resume + role context
  │     ├── POST to Claude API  (claude-sonnet-4-5, max_tokens=2048)
  │     ├── Parse JSON from Claude response
  │     └── Validate: ≥ 3 questions per category
  │
  ├── On Claude API error → raise ClaudeServiceError → HTTP 502
  └── Return GenerateResponse  (200 OK)
        {
          "technical":    [ { text, follow_up, what_to_listen_for }, … ],
          "behavioural":  [ … ],
          "culture_fit":  [ … ]
        }
```

### Request Schema (`GenerateRequest`)

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `resume_text` | `str` | Yes | Raw extracted text from the candidate's resume |
| `job_title` | `str` | Yes | Job title being interviewed for |
| `seniority_level` | `str` | Yes | e.g. "Junior", "Mid", "Senior", "Lead" |
| `key_skills` | `list[str]` | Yes | List of required skills for the role |

### Response Schema (`GenerateResponse`)

| Field | Type | Description |
|-------|------|-------------|
| `technical` | `Question[]` | Domain knowledge and hands-on skill questions |
| `behavioural` | `Question[]` | STAR-format questions about past experiences |
| `culture_fit` | `Question[]` | Questions probing values, work style, and team fit |

Each `Question` contains:

| Field | Type | Description |
|-------|------|-------------|
| `text` | `str` | The interview question |
| `follow_up` | `str` | One suggested follow-up question |
| `what_to_listen_for` | `str` | Coaching note on what a strong answer contains |

### Service Layer (`claude_service.py`)

- **Model:** `claude-sonnet-4-5` with `max_tokens=2048`
- **System prompt:** Instructs Claude to return valid JSON only, no prose or markdown fences
- **User prompt:** Combines resume text, job title, seniority level, and key skills
- **Validation:** Checks for all three required categories and minimum 3 questions per category
- **Error handling:** Wraps all Claude SDK errors in `ClaudeServiceError` with status code 502

### Error Handling

| Error Type | HTTP Status | Message |
|------------|-------------|---------|
| Missing/empty fields | 422 | Field-specific validation message |
| Claude API failure | 502 | "The AI service is temporarily unavailable..." |
| Non-JSON response | 502 | "The AI service returned an unexpected response..." |
| Incomplete response | 502 | "The AI service returned an incomplete response..." |
| Too few questions | 502 | "The AI service returned too few questions..." |

## Edge Cases & Risks

| Scenario | Mitigation |
|----------|-----------|
| Claude returns fewer than 3 questions per category | `_parse_response` raises `ClaudeServiceError`; router returns 502 |
| Claude returns markdown-fenced JSON | System prompt explicitly forbids fences; service validates JSON structure |
| Claude returns valid JSON but wrong keys | Service checks for all three required keys |
| `ANTHROPIC_API_KEY` missing | `anthropic.Anthropic()` raises error; caught and returns 502 |
| Claude rate limit hit (429) | `anthropic.APIError` caught → 502 with user-friendly message |
| Claude API connection timeout | `anthropic.APIError` caught → 502 with connectivity message |
| Very long resume (token limit) | Claude will truncate or error; consider truncating before sending |
| No auth on `/generate` endpoint | Consistent with M1/M2 scope; add guard in later milestone |

## Notes

- **Model selection:** `claude-sonnet-4-5` provides better output quality than Haiku for structured generation.
- **No frontend changes in this issue:** The `POST /generate` endpoint is backend-only. Frontend integration is a separate issue.
- **No persistence:** Generated question sets are not stored in the database at M2.
- **Prompt caching:** The static `_SYSTEM_PROMPT` is a candidate for Anthropic's prompt caching feature in a follow-up.
